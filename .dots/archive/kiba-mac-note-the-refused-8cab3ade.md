Problem: HTTPClient.renew (Sources/KibaCore/Probe.swift ~125-140) returns Renewal.refused for a token endpoint's 400/401 and drops the body; ClaudeProbe.renewed (ClaudeProbe.swift ~102-111) maps it to .stale(.expired, Note.refused), fixed text "access token expired and the refresh was refused; log in again". The row never shows what Anthropic answered, and an account on hold is shown as "log in again". A 403 on hold reads "Anthropic's token endpoint answered 403" because renew classifies status before any probe sees the body. Codex (CodexProbe.renewed ~84-94) shares renew and must keep its exact behaviour, including .stale(.revoked, …) -> ProbeOutcome.revoked -> Switcher.record removing the row (Switcher.swift ~266).

Facts (read from Claude Code 2.1.285's binary): a token endpoint error answer is read as code = `error` when it is a string, else `error.type` when `error` is an object; description = `error_description`. On hold = status 400, 401 or 403 with code "invalid_grant" or "access_denied" and description exactly "account_on_hold", optional `error_uri`; fallback page https://claude.ai/restricted. Dead grant = 400/401 with code invalid_grant, not on hold. Claude Code has no "no plan" branch at refresh.
